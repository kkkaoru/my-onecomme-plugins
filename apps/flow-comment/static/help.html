流れるコメント 使い方

わんコメのコメントを、画面の右から左へ流して表示します。スーパーチャット・ギフト・メンバー加入は YouTube と同じ色のカードで流れます。設定は入力を止めると自動で保存されます。

1. 入れる

配布は zip が3つあります。

  • all_flow-comment.zip … まとめ。展開すると plugin_flow-comment と template_flow-comment.zip が出る
  • plugin_flow-comment.zip … 展開し、plugin_flow-comment フォルダをプラグインフォルダへコピーする
  • template_flow-comment.zip … 展開しない。テンプレート一覧へドラッグ＆ドロップする
  1. わんコメ右上メニュー → プラグイン →「プラグインフォルダ」を開く
  2. plugin_flow-comment をコピーする（直下に plugin.js があること）
  3. プラグイン一覧で再読み込みし、「流れるコメント」を有効化する
  4. template_flow-comment.zip をテンプレート一覧へドロップする（中を展開するとフォルダが二重になる）
  5. テンプレート「流れるコメント」を選ぶ

2. 設定画面を開く

  1. わんコメ右上メニュー → プラグイン
  2. 「流れるコメント」を有効化する
  3. 一覧の URL ボタンを押す

またはブラウザで http://localhost:11180/plugins/com.example.my-onecomme-plugins.flow-comment/ を開く。

3. 見た目を変える

  • プレビューで文字サイズ・色・レーンを確認する
  • 値を変えると自動保存され、配信側にも反映される
  • 「初期値に戻す」で出荷時の設定に戻る

4. OBS に出す

  1. OBS に「ブラウザ」ソースを追加し、わんコメの配信画面 URL を指定する
  2. プロパティの「FPS」を 60 にする（既定は 30）
  3. 幅と高さは配信と同じにする（例: 1920×1080）
  4. 設定を変えたあとは、ソースを右クリックして「ブラウザを更新」する
