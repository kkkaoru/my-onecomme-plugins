# 流れるコメント

わんコメ（OneComme）向けのコメント演出です。コメントが画面を右から左（または左から右）へ流れます。

この zip には次の2つが入っています。

| フォルダ                | 役割                   |
| ----------------------- | ---------------------- |
| `plugin/flow-comment`   | 設定の保存と設定画面   |
| `template/flow-comment` | 配信画面に流れる見た目 |

テンプレートだけでも既定値で流れます。色・速度・フォントなどを変えるにはプラグインも入れて有効化してください。

GitHub の **Source code** はリポジトリ全体なので使わないでください。使うのはこの `flow-comment.zip` です。

## 必要環境

- わんコメ 5.2 以上

## インストール

zip を展開します。

### 1. プラグイン

1. わんコメ右上メニュー → **プラグイン**
2. **プラグインフォルダ** を開く
3. 展開した `plugin/flow-comment` フォルダを、その中へコピーする（`plugin.js` が `plugins/flow-comment/plugin.js` になること）
4. プラグイン一覧で **再読み込み** し、**流れるコメント** を有効化する

### 2. テンプレート

次のどちらかです。

- 展開した `template/flow-comment` フォルダを、わんコメのデータフォルダの `templates/custom/` へコピーする（フォルダ名は `flow-comment` のまま）
- または `template/flow-comment` を zip し直し、テンプレート一覧へドラッグ＆ドロップする

データフォルダの例:

- macOS: `~/Library/Application Support/OneComme/`
- Windows: `%APPDATA%/OneComme/`

配置後、わんコメでテンプレート **流れるコメント** を選びます。

## 使い方

1. わんコメでテンプレート「流れるコメント」を選ぶ
2. プラグイン「流れるコメント」を有効化する（設定を変える場合）
3. OBS にブラウザソースを追加し、わんコメの配信画面 URL を指定する
4. ブラウザソースの解像度は配信と同じにする（例: 1920×1080）
5. OBS のブラウザソースは **FPS 60** にする（既定 30 だと流れが粗い）

設定画面はプラグイン一覧の URL ボタン、または次のアドレスです。

```
http://localhost:11180/plugins/com.example.my-onecomme-plugins.flow-comment/
```

設定を変えたあとは、OBS のブラウザソースを右クリックして **ブラウザを更新** してください。プラグイン本体（`plugin.js`）を差し替えたときは、プラグインを一度無効→有効にするか、わんコメを再起動します。

## アンインストール

1. プラグインを無効化する
2. `plugins/flow-comment` を削除する
3. `templates/custom/flow-comment` を削除する
