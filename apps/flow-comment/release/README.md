# 流れるコメント

わんコメ専用のコメントテンプレート＋設定プラグインです。コメントが画面を右から左へ流れます（左から右にも変更できます）。YouTube のスーパーチャット・ギフト・メンバー加入は、配信と同じ色のカードで流れます。

この zip の中身:

| フォルダ                | 役割                 |
| ----------------------- | -------------------- |
| `plugin/flow-comment`   | 設定の保存と設定画面 |
| `template/flow-comment` | 配信に出す見た目     |

テンプレートだけでも既定値で流れます。色・速度・フォントなどを変えるときはプラグインも入れて有効化してください。

リポジトリ: https://github.com/kkkaoru/my-onecomme-plugins

最新版: https://github.com/kkkaoru/my-onecomme-plugins/releases

GitHub の Source code はリポジトリ全体なので使わないでください。

## 必要環境

- わんコメ 5.2 以上
- OBS（ブラウザソース）

## インストール

zip を展開します。

### プラグイン

1. わんコメ右上メニュー → **プラグイン**
2. **プラグインフォルダ** を開く
3. `plugin/flow-comment` をその中へコピーする（`plugin.js` がそのフォルダ直下にあること）
4. プラグイン一覧で **再読み込み** し、**流れるコメント** を有効化する

### テンプレート

次のどちらかです。

- `template/flow-comment` をわんコメのテンプレート一覧へドラッグ＆ドロップする
- またはデータフォルダの `templates/custom/` に `flow-comment` フォルダごと置く

データフォルダの例:

- macOS: `~/Library/Application Support/OneComme/`
- Windows: `%APPDATA%/OneComme/`

わんコメでテンプレート **流れるコメント** を選び、OBS へ入れます。

## 設定画面の開き方

プラグインを有効化したあと、次のどちらかです。

1. わんコメ右上メニュー → **プラグイン** を開く
2. 一覧の「流れるコメント」行にある **URL** ボタンを押す

またはブラウザで次のアドレスを開く。

```
http://localhost:11180/plugins/com.example.my-onecomme-plugins.flow-comment/
```

設定は入力を止めると自動で保存され、配信側にも反映されます。反映されないときは OBS のブラウザソースを右クリックして **ブラウザを更新** してください。`plugin.js` を差し替えたときは、プラグインを一度無効→有効にするか、わんコメを再起動します。

## OBS

1. ブラウザソースを追加し、わんコメの配信画面 URL を指定する
2. 幅と高さは配信と同じにする（例: 1920×1080）
3. ブラウザソースの FPS を 60 にする（既定 30 だと流れが粗い）

## アンインストール

1. プラグインを無効化する
2. `plugins/flow-comment` を削除する
3. `templates/custom/flow-comment` を削除する
